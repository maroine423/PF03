# PF03 - Actividad 1

Proyecto individual de desarrollo con Node.js utilizando
la metodología TDD (Red, Green, Refactor).

## Funciones

- fibonacci(n): calcula un término de la sucesión de Fibonacci.
- esPinValido(pin): comprueba si un PIN cumple los requisitos establecidos.

## Pruebas

Las pruebas unitarias se ejecutan mediante Node.js con:

npm test

## Integración continua

El proyecto utiliza GitHub Actions para ejecutar
automáticamente las pruebas.
